# Vintage Story Panel 0.3.0

Second release of the .NET panel for dedicated Vintage Story servers on Linux and Windows.

## New

- Host overview: CPU, memory, swap, load average and the disks that hold panel state, server
  data and backups, on the overview page.
- Game ports in the firewall: the panel opens a server's port when the server is created,
  moves the rule when the port changes in server settings, and removes it when the server is
  deleted (ufw on Linux, Windows Firewall on Windows). `PANEL_FIREWALL=off` leaves the firewall
  alone; a firewall failure is shown as a warning and does not fail the operation.
- A Russian user guide and resource sizing in the README.

## Changed

- Lower memory use: logs, telemetry and history files are streamed instead of read whole,
  the mod image cache is smaller, and the panel and daemon use workstation GC.
- Directory moves during backups and game updates retry on transient Windows file locks.
- The login throttle no longer grows without bound.

## Fixed

- Windows: `install.cmd` failed to request administrator rights when its path or arguments
  contained an apostrophe.
- Windows: `vs-panel` failed when the environment contained both `Path` and `PATH`
  (for example, when started from MSYS or Git Bash).

## Installation

Linux (x86-64 or ARM64 with systemd):

```sh
curl -fsSL https://raw.githubusercontent.com/pander33/vintage-story-server-panel/v0.3.0/deploy/get.sh | sudo VS_PANEL_VERSION=0.3.0 sh
```

Windows (x86-64), in Windows PowerShell 5.1 or PowerShell 7:

```powershell
$env:VS_PANEL_VERSION = '0.3.0'
irm https://raw.githubusercontent.com/pander33/vintage-story-server-panel/v0.3.0/deploy/windows/get.ps1 | iex
```

An existing 0.2.0 installation is updated in place with `vs-panel update` (Linux: `sudo vs-panel update`;
Windows: from an Administrator command prompt). The previous version is kept for `vs-panel rollback`.
See the [README](https://github.com/pander33/vintage-story-server-panel/blob/v0.3.0/README.md)
for installation options and HTTPS configuration.

## Downloads

| Asset | Target |
|---|---|
| `vs-panel-linux-x64.tar.gz` | Linux x86-64 |
| `vs-panel-linux-arm64.tar.gz` | Linux ARM64 |
| `vs-panel-win-x64.zip` | Windows x86-64 |
| `get.sh`, `get.ps1` | Bootstrap scripts from this release |
| `SHA256SUMS` | SHA-256 checksums of the five files above |

Each package contains the three self-contained executables, `VERSION`, `RID`, the platform
installer and the telemetry mod `vspaneltelemetry` 0.4.0. A separate .NET installation is not
required for the panel; the installer prepares the runtime needed by the game. Windows ARM64
and 32-bit systems are not supported by these packages.

## Early-release limitations

This is an early release. Back up game worlds and panel state before updating. Linux systemd,
permissions, firewall and game/archive operations, and a complete installation in a clean
Windows environment need integration checks on their target systems; build and unit-test
results alone do not certify those scenarios. The panel serves HTTP by default: configure
HTTPS or an SSH tunnel before exposing it outside a trusted local network.
