# Vintage Story Panel 0.2.0

First release of the .NET panel for dedicated Vintage Story servers on Linux and Windows.
One panel manages multiple servers; the web interface and setup wizard are available in
English and Russian.

## Included

- Server creation and removal, start/stop/restart, readiness and resource monitoring.
- Players, chat, console commands, bans, whitelist and connection history.
- Worlds, mods, ModDB, mod packs, backups and restore.
- Server settings, world templates, live world configuration and mod settings.
- Scheduled maintenance, watchdog, game and mod updates with recovery history.
- Logs, diagnostics, events, notifications, accounts, roles and two-factor authentication.
- One-command installation and panel updates from GitHub Releases, with SHA-256 verification.
- Server telemetry mod `vspaneltelemetry` 0.4.0, bundled in every package.

## Installation

Linux (x86-64 or ARM64 with systemd):

```sh
curl -fsSL https://raw.githubusercontent.com/ruslan120p/vintage-story-panel-net/v0.2.0/deploy/get.sh | sudo VS_PANEL_VERSION=0.2.0 sh
```

Windows (x86-64), in Windows PowerShell 5.1 or PowerShell 7:

```powershell
$env:VS_PANEL_VERSION = '0.2.0'
irm https://raw.githubusercontent.com/ruslan120p/vintage-story-panel-net/v0.2.0/deploy/windows/get.ps1 | iex
```

The installer requests administrator privileges on Windows. It prints a one-time link to
the setup wizard, where you create the administrator account. By default the panel is
available on the local network on port 8080. See the [README](https://github.com/ruslan120p/vintage-story-panel-net/blob/v0.2.0/README.md)
for installation options and HTTPS configuration.

## Downloads

| Asset | Target |
|---|---|
| `vs-panel-linux-x64.tar.gz` | Linux x86-64 |
| `vs-panel-linux-arm64.tar.gz` | Linux ARM64 |
| `vs-panel-win-x64.zip` | Windows x86-64 |
| `get.sh`, `get.ps1` | Bootstrap scripts from this release |
| `SHA256SUMS` | SHA-256 checksums of the five files above |

Each package contains the three self-contained executables, `VERSION`, `RID`, the platform
installer and the telemetry mod. A separate .NET installation is not required for the panel;
the installer prepares the runtime needed by the game. Windows ARM64 and 32-bit systems are
not supported by these packages.

## Early-release limitations

This is an early release. Back up game worlds and panel state before updating. Linux systemd,
permissions and game/archive operations, and a complete installation in a clean Windows
environment need integration checks on their target systems; build and unit-test results
alone do not certify those scenarios. The panel serves HTTP by default: configure HTTPS or
an SSH tunnel before exposing it outside a trusted local network.
