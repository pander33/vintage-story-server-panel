First login

The installer printed a one-time token. It proves that the panel is being set up by someone with access to the server, not just whoever opened the port first.

Claim token not found. On the server, run sudo vs-panel-claim and open the printed link.

Continue installation

The administrator is already created and the claim token is spent. Log in to return to the unfinished installation.

Panel access

Where the panel will listen. By default — all network interfaces: the panel is visible from the local network, the firewall rule is opened only for it and follows address/port changes. It is safer to keep only this machine and connect through an SSH tunnel. To open the panel to the internet — at install time: vs-panel repair --access internet.

The panel will become reachable from the network. Put it behind an HTTPS proxy and enable HTTPS-only cookies, otherwise the password travels over an open channel.

The new address takes effect after the panel restarts at the end of setup.

Creating server

    Done

    What's next

    • Create a server in the panel: "Overview" → "New server".
    • Open the "Content" tab and install mods — the panel looks them up in the official database.
    • On the "Maintenance" tab, enable the backup schedule and the watchdog.
    • Players connect using the server address and the port set at creation.
