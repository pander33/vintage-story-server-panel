    Server archives

    The server stops gracefully while a backup is created. The last backup cannot be deleted.

    Extract a single world from a backup

    The world will appear as a separate file, without replacing the active one.

    Old backup cleanup

    A one-off operation. A backup is deleted only if it is both extra by count and older than the limit. The panel first shows the exact list.

    Server transfer

    Export the selected server and import an archive as a new server. The archive is checked before creation; existing servers are not replaced.

    Check the world and set the parameters for the new server. Choose the game version, identifier and port explicitly: the current server is not changed.

    Accumulated history

    Previous mod versions and config backups. The backup retention policy does not apply to them.

    Users
