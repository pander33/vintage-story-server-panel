    ИГРОВОЙ МИР / КОНТЕНТ

    Миры и моды

    Файлы мира, модификации и совместимость с версией игры.

    Файлы миров

    Активный мир отмечен; переключение, клонирование и архив — при остановленном сервере.

    Подготовить новый мир

    Панель настроит новый файл; сам мир создаст игра при следующем запуске.

    Установленные моды

    Зависимости проверяются по modinfo.json и версии игры сервера.

    Последние сообщения модов при запуске

    Наборы модов

    Снимок списка включённых архивов. Применение требует перезапуска.

    Откат версии

    Заменённые версии хранятся в Mods/.history и возвращаются одной кнопкой.

    Поиск в ModDB

    Панель установит только выбранный релиз, совместимый с версией игры сервера.

    Архив и корзина миров

    Восстанавливайте убранные миры без замены текущего. Для восстановления сервер должен быть остановлен.

    НАДЁЖНОСТЬ / КОПИИ

    Резервные копии

    Создание, проверка, восстановление и очистка хранилища.

    ПОСЛЕДНЯЯ КОПИЯ——
    ВСЕГО КОПИЙ——
    СВОБОДНО НА ДИСКЕ——

    Архивы сервера

    На время создания копии сервер корректно останавливается. Последнюю копию удалить нельзя.

    Извлечь один мир из копии

    Мир появится отдельным файлом без замены активного.

    Очистка старых копий

    Разовая операция. Копия удаляется, только если она и лишняя по счёту, и старше срока. Сначала панель покажет точный список.

    Перенос сервера

    Экспорт выбранного сервера и импорт архива как нового сервера. Архив проверяется перед созданием; существующие серверы не заменяются.

    Проверьте мир и задайте параметры нового сервера. Версию игры, идентификатор и порт выберите явно: текущий сервер не меняется.

    Накопленная история

    Прежние версии модов и копии конфигураций. Политика хранения копий на них не действует.

    ДНИ НЕДЕЛИ

    Время отсчитывается от первого предупреждения: сервер остановится после обратного отсчёта.

    Состояние готовности

    Готовность — только свежая телеметрия текущего процесса

    Если мод телеметрии отсутствует, состояние будет «Ограниченная проверка», и автоматический перезапуск не выполняется никогда.

    Правила наблюдения

    Обновления модов

    Стабильные совместимые релизы скачиваются заранее, затем создаётся копия офлайн. При ошибке панель вернёт прежние версии.

    Vintage Story Server

    Официальный пакет сервера. До загрузки панель проверит совместимость установленных модов, затем сохранит программу и данные для отката.

    ПАРАМЕТРЫ / КОНФИГУРАЦИЯ

    Настройки

    Параметры выбранного сервера и общие настройки панели разделены.

    —

    serverconfig.json

    Поля проверяются; неизвестные параметры сохраняются. Перед записью создаётся копия.

    Расширенный JSON

    Для параметров, которых нет в форме. Изменения применяются к форме, сохраняются кнопкой «Сохранить».

    Откат конфигурации

    Текущий мир

    Значения приходят из телеметрии работающего мира. Меняются только разрешёнными командами игры.

    Шаблон нового мира

    WorldConfig.WorldConfiguration применяется только при создании следующего мира.

    Конфигурация модов

    JSON-файлы из ModConfig; перед заменой создаётся .bak.

    Пользователи

    Наблюдатель читает данные. Оператор управляет службой, игроками и создаёт копии. Администратор меняет миры, моды, настройки, обновления и пользуется произвольной консолью.

    Создать или сменить пароль

    Второй фактор для —

    Одноразовые коды из приложения-аутентификатора. Включение и отключение требуют текущего пароля.

    Уведомления панели

    Общие для всех серверов. Сохранённые секреты не показываются; пустое поле не меняет сохранённое значение.

    Каталог игровых серверов

    Здесь создаются новые серверы: программа игры, миры, моды и резервные копии. Уже созданные серверы остаются на своих местах.

    НОВЫЙ СЕРВЕР

    Создание игрового мира

    Проверка машины → пакет игры со сверкой md5 → каталоги и служба → первый запуск. Идентификатор потом не меняется.
